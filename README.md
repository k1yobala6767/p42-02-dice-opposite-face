## Условие

Дано целое число n — номер грани стандартной шестигранной игральной кости. Грани пронумерованы от 1 до 6. Найдите число на противоположной грани.

**Примеры**

```
Вход: n = 2
Выход: 5
Пояснение: напротив грани 2 находится грань 5.

Вход: n = 6
Выход: 1
Пояснение: напротив грани 6 находится грань 1.
```

## Как выполнить

1. Один человек из команды нажимает **Fork** (вверху справа) и добавляет напарника: Settings → Collaborators → Add people.
2. Оба клонируют форк и открывают его в VS Code:
   ```
   git clone https://github.com/<ваш-ник>/p42-02-dice-opposite-face
   cd p42-02-dice-opposite-face
   code .
   ```
3. Впишите в таблицу «Команда» выше свои ФИО и ники GitHub.
4. В `Program.cs` напишите решение внутри метода `OppositeFace` (вместо строки `return 0;`). Метод `Main` и `Check` не меняйте.
5. Запустите:
   ```
   dotnet run
   ```
   Все проверки должны показать `OK`.
6. Сохраните работу в GitHub (коммитят оба участника):
   ```
   git add .
   git commit -m "Решение"
   git push
   ```
